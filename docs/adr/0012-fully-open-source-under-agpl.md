# Fully open source under AGPL

Theobase is fully open source — core and modules — licensed under AGPL, with Taia Tiniyara, LLC selling the operated SaaS rather than the software. Self-hosting by a Subscriber is free and permitted but unsupported. We chose AGPL over a permissive license so a competitor cannot fork, add features, and sell a closed hosted rival; full code visibility is also the trust mechanism that lets a denomination run its members' data on the system.

Consequences: the $3 subscription (ADR-0010) is a price for operation, not access, and is optional for anyone willing to run their own infrastructure. The moat is operational — hosting, support, and the policy-data feed (ADR-0013) — rather than code. "Theobase" remains a trademark so a fork cannot use the name.
