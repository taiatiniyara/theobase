# Contacting Support

## Overview

Theobase support is available to help with technical issues, account questions, and platform guidance.

## How to Contact Support

**Email**: support@theobase.app

This is the primary support channel. All support requests are handled via email.

## Response Time

We aim to respond to all support requests within **1 business day** (Monday through Friday, excluding holidays). Urgent issues (service outage, data loss, inability to log in) are prioritized.

## What to Include in Your Request

To help us resolve your issue quickly, include the following in your support email:

### Required Information

- **Your name and role** (e.g., "John Smith, Conference Treasurer").
- **Conference name** (e.g., "North Caribbean Conference").
- **Church name** (if the issue is specific to a church).
- **Clear description of the problem**: What you were trying to do, what you expected to happen, and what actually happened.
- **Steps to reproduce**: The exact sequence of actions that led to the issue. For example: "Logged in → clicked Finance → clicked New Batch → entered amounts → clicked Submit → got a 500 error."

### Helpful Extras

- **Screenshots**: A screenshot of the error or unexpected behavior is extremely helpful. Include the full browser window so we can see the URL and any visible error messages.
- **Date and time**: When the issue occurred (with your timezone).
- **Browser**: Which browser and version you're using (Chrome, Firefox, Safari, Edge).
- **Error messages**: Copy and paste the exact text of any error message, including error codes.

### Good Example

> Subject: Cannot confirm offering batch — Bethlehem SDA Church
>
> I'm the Assistant Treasurer at Bethlehem SDA Church (North Caribbean Conference). When I try to confirm batch #47 for May 24, 2025, I get a red error saying "Batch is already confirmed" — but the batch still shows as "Submitted" on the list. I've tried refreshing the page and logging out/in.
>
> Steps: Logged in → Finance → Batches → Pending Confirmation → Click batch #47 → Click Confirm → Error appears.
>
> Screenshot attached.
>
> Browser: Chrome 126 on Windows 11. Time: July 25, 2025, 3:30 PM EST.

## What Not to Include

- **Passwords**: Never include your password in a support email.
- **Full credit card or banking details**: If there's a billing issue, we'll direct you to Stripe's secure portal.
- **Sensitive member data** (full birth dates, addresses): Describe the issue without including personal details of individual church members.

## Self-Help Resources

Before contacting support, check these resources:

- **Domain glossary** (CONTEXT.md): Definitions of SDA-specific terms used in the platform.

## Feature Requests

We welcome feature suggestions. Send them to the same email address with "Feature Request" in the subject line. Include:

- What problem the feature would solve.
- Who would use it (clerks, treasurers, pastors, Conference admins).
- How you currently handle this without the feature.
- Any specific requirements or examples.

## Reporting Bugs

If you believe you've found a bug:

1. Document the steps to reproduce it.
2. Note the expected vs. actual behavior.
3. Include screenshots and browser info.
4. Send to support@theobase.app with "Bug Report" in the subject line.

Security vulnerabilities should be reported separately — see the Security Audit documentation for our responsible disclosure process.
