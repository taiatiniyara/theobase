# Conference Dashboard

## Overview

The Conference Dashboard provides a high-level view of all churches, members, and finances within your Conference. It's the first page you see after logging in as a Conference administrator.

## What You See

### Church Summary

A statistics row showing:

- **Total Churches**: Count of all organized churches, companies, and branches.
- **Total Membership**: Aggregate active membership across all churches.
- **Tithe This Month**: Total tithe forwarded by all churches for the current month.
- **Baptisms This Year**: Count of new members joined by baptism (immersion) this calendar year.

### Church List

A searchable, sortable table of every church in your Conference:

| Column       | Description                     |
| ------------ | ------------------------------- |
| Name         | Church name                     |
| Type         | Organized / Company / Branch    |
| District     | Assigned district (if any)      |
| Members      | Active membership count         |
| Tithe (MTD)  | Tithe forwarded this month      |
| Baptisms YTD | Baptisms by immersion this year |

Click any church to drill down into its detail view.

### Tithe Totals

A summary of tithe forwarded by churches in the current month. For detailed per-church reconciliation of forwarded vs. received amounts, see the Reconciliation guide.

### Membership Trends

Current membership stats are displayed on the dashboard:

- Total active membership across all churches.
- Baptisms by immersion this calendar year.
- For detailed membership reports, use the Quarterly Business Meeting Report.

### Quick Actions

From the dashboard, you can:

- **Add Church**: Create a new church in the Conference.
- **View Transfers**: Navigate to pending member transfers awaiting approval.
- **Reconciliation**: Go to the tithe reconciliation view.
- **Reports**: Access the Conference-level dashboard report.

## Filtering

Use the filters at the top of the dashboard to:

- View data for a specific district.
- Toggle between organized churches, companies, and branches.
- Set a date range for financial data.

## District Dashboard

District pastors see a similar dashboard scoped to their assigned churches. Navigate to it by selecting your district from the dashboard dropdown or clicking a district name in the church list.

## Global Dashboard

Users with the Auditor or Conference-level roles can access the **Global Dashboard** for aggregate stats across all Conferences (read-only). This is useful for Union and Division-level reporting.
