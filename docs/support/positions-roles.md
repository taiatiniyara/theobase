# Positions and Roles

## Overview

In Theobase, **positions** are church-level offices that members hold (Elder, Treasurer, Clerk, Deacon). **Roles** are system-level permissions that control what a user can do in the platform.

This guide covers assigning church positions to members.

## Standard Church Positions

Theobase comes with these pre-configured positions:

| Position                      | Description                                              |
| ----------------------------- | -------------------------------------------------------- |
| Elder                         | Local church elder, responsible for spiritual leadership |
| Head Elder                    | Lead elder coordinating the elder team                   |
| Treasurer                     | Manages church finances and offering batches             |
| Assistant Treasurer           | Second person for dual-custody batch confirmation        |
| Clerk                         | Manages membership records and transfers                 |
| Assistant Clerk               | Assists with membership and attendance entry             |
| Deacon                        | Assists with church services and facilities              |
| Deaconess                     | Assists with hospitality and member care                 |
| Sabbath School Superintendent | Coordinates Sabbath School program                       |
| Personal Ministries Leader    | Coordinates outreach and evangelism                      |
| Youth Leader                  | Coordinates youth activities (AYS)                       |
| Pathfinder Director           | Leads Pathfinder club                                    |
| Adventurer Director           | Leads Adventurer club                                    |

Conferences can add custom positions if needed.

## Assigning a Position to a Member

1. Open the member's profile from the church's member list.
2. Click the **Positions** tab.
3. Click **Assign Position**.
4. Select the position from the dropdown.
5. Optionally set a start date (defaults to today).
6. Click **Save**.

A member can hold multiple positions simultaneously (e.g., a person can be both Elder and Sabbath School Superintendent).

## Removing a Position

1. From the member's Positions tab, find the position to remove.
2. Click the **X** or **Remove** button next to it.
3. Optionally enter an end date.
4. Confirm.

The position is removed but the history remains in the member's activity log.

## Viewing All Position Holders

From the church detail page, navigate to **Positions** to see a roster of every position and who currently holds it. This is useful for:

- Preparing the church board list for the quarterly report.
- Checking for vacant positions that need filling.
- Verifying that dual-custody positions (Treasurer + Assistant Treasurer) are both assigned.

## Benefits

Position assignments feed automatically into:

- The Quarterly Business Meeting Report (officers section).
- Church directories and rosters.
- Permissions: assigning the Treasurer position doesn't automatically grant system access — you must also invite the person as a user and assign the appropriate system role.
