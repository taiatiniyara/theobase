# Quarterly Business Meeting Report

## Overview

The Quarterly Business Meeting Report is presented to the full congregation at the quarterly church business meeting. It brings together three sections — Membership, Finance, and Officers — that are auto-compiled from data already in the system. No manual compilation is required.

## Generating the Report

1. From the church dashboard, navigate to **Reports → Quarterly Report**.
2. Select the **quarter** and **year** (e.g., Q2 2025).
3. The report generates in real time from current system data.

## Report Sections

### Section 1: Membership (Presented by the Clerk)

| Item                     | Source                                              |
| ------------------------ | --------------------------------------------------- |
| Opening membership count | Auto-calculated from previous quarter's closing     |
| Baptisms (immersion)     | Count of new members joined by baptism this quarter |
| Professions of faith     | Count of members joined by profession of faith      |
| Transfers in             | Members received from other churches                |
| Transfers out            | Members transferred to other churches               |
| Deaths                   | Members deceased this quarter                       |
| Removals                 | Members removed (apostasy, missing)                 |
| Closing membership count | Opening + additions - removals                      |

### Section 2: Finance (Presented by the Treasurer)

| Item                       | Source                                  |
| -------------------------- | --------------------------------------- |
| Tithe received             | Sum of all tithe from confirmed batches |
| Sabbath School Offerings   | Sum of all Sabbath School offerings     |
| Local Church Budget income | Offerings received for local budget     |
| Expenses by category       | Actual vs. budgeted, with variance      |
| Closing balances           | Per-fund balances at quarter end        |

### Section 3: Officers (Presented by the Clerk)

Lists all current church officers with their positions. Pulled directly from the position assignments in the system. Shows:

- Each position and who currently holds it.
- Any positions that are vacant.
- Positions added or changed since the last quarterly report.

## Printing and Presenting

1. Click **Export PDF** for a formatted report suitable for distribution.
2. The report includes cover page, section headers, and summary page.
3. Each section is clearly separated so the Clerk and Treasurer can present their respective parts.

## Auditor Role Notes

The quarterly report draws from the same source data as the monthly treasurer report and the audit trail. If the quarterly report looks off:

- Check that all offering batches for the quarter are in "Confirmed" status.
- Verify that all expense entries for the quarter are recorded.
- Cross-reference membership numbers against individual member statuses.

## Tips

- Generate a draft a week before the business meeting to catch any missing entries.
- The system remembers which quarter was last presented — it pre-selects the next quarter for you.
- The opening membership count is derived automatically from the previous quarter's report — you don't need to enter it.
