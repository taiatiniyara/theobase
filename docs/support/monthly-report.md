# Monthly Treasurer Report

## Overview

The Monthly Treasurer Report is an auto-generated financial summary that the Treasurer presents to the church board each month. It shows income by fund, expenses by category, and opening/closing balances — all automatically compiled from confirmed batches and recorded expenses.

## Generating the Report

1. From the church dashboard, navigate to **Finance → Monthly Report**.
2. Select the **month and year** from the dropdown. The current month is pre-selected.
3. The report generates automatically.

## What's in the Report

### Income Section

Lists all income received during the month, broken down by fund:

- **Tithe**: Total tithe received from members.
- **Local Church Budget**: Offerings designated for local church operations.
- **Sabbath School Offering**: Offerings collected for world mission.

Each fund shows the monthly total and a year-to-date running total.

### Expense Section

Lists expenses grouped by category (Utilities, Maintenance, Supplies, Evangelism, etc.):

| Column           | Description                                    |
| ---------------- | ---------------------------------------------- |
| Category         | Expense category name                          |
| Budgeted         | Amount allocated in the approved annual budget |
| Spent This Month | Total expenses in this category for the month  |
| Remaining        | Budgeted minus spent this month                |
| % Used           | Percentage of annual budget consumed           |

### Balance Summary

- **Opening Balance**: The closing balance from the previous month's report (auto-derived).
- **Total Income**: Sum of all income for the month.
- **Total Expenses**: Sum of all expenses for the month.
- **Closing Balance**: Opening + Income - Expenses.

### Notes and Attachments

The Treasurer can add free-text notes (e.g., "Roof repair was an unbudgeted emergency expense") before presenting the report.

## Exporting

Click **Export PDF** to download a formatted version of the report suitable for printing and distribution at the church board meeting. Click **Export CSV** for raw data export.

## Re-running Reports

Monthly reports are always recalculated from source data when opened — no stored snapshots. If a batch was confirmed late (after the initial report was generated), simply re-open the report for that month to get updated figures.

## Validation

Before presenting, verify:

- All offering batches for the month are confirmed.
- All expenses for the month are entered.
- The opening balance matches the previous month's closing balance per the bank statement.
- Any discrepancies are noted and reconciled (see the Reconciliation guide).
